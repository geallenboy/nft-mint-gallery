## 1. 今天要达成什么

### 目标（MVP）
在 **Ethereum Sepolia 测试网**上，一个人能跑通：

1. 前端连接钱包（MetaMask）
2. 部署一个简单 **ERC-721**
3. 网页：**铸造** → **展示当前地址持有的 NFT** → **看 tokenURI / 图片**
4. 加分：监听 `Transfer` 或手动刷新持仓
5. 文档可复现；**不上主网、不碰真金、不做交易所**

### 明确不做
订单簿、挂单吃单、版税引擎、多链、主网发布、完整 IPFS 上传流水线（Pinata 可后补）。

### 为什么这个范围
对齐「以后要维护 NFT Web 交易所」的前置技能：**合约最小面 + 钱包签名 mint + 持仓橱窗**，先建立肌肉记忆，再往交易所加复杂度。

## 5. 核心概念（对照代码）

### 合约 `SimpleCollectible`
- `mint(to, uri)`：公开铸造（学习用，非生产权限模型）
- `tokenURI`：元数据或直链图片 URL（`https://` / `ipfs://`）
- `tokensOfOwner`：O(n) 枚举持仓（体量小才合适）
- `Transfer` / `Minted` 事件：前端刷新依据

### 前端
- `wagmi`：读合约、写 `mint`、等回执
- `Gallery`：拉持仓 → `loadMetadata(tokenURI)` → 展示图
- Provider：`WagmiProvider` + React Query（与主流模板同构）

### tokenURI 两种形态
1. **直链图片**（今天默认 placehold）→ 当 `image` 用  
2. **JSON 元数据**（标准 NFT）→ 解析 `name/description/image`

## 6. 今日踩坑实录（很值钱）

| 坑 | 现象 | 处理 |
|----|------|------|
| 空目录 | `web3` 里只有 `.` `..`，无法 forge | 逐文件 CopyFromBox 落到正确路径；后改为 `nft-mint-gallery/` |
| tar 解错位置 | 以为解压了其实项目根仍空 | 以「能 ls 到 contracts/apps」为准，不信感觉 |
| Mac Cursor shell `zsh ENOENT` | 代理无法本机执行命令 | CopyFromBox + 本机终端手动 forge/npm |
| placehold 无 `.png` 后缀 | mint 成功但橱窗 meta error | `Gallery.loadMetadata`：识别 placehold、`/png` 路径段、`Content-Type: image/*`，勿对图片硬 `json()` |
| RainbowKit 构建失败 | `next build` 拉到 `@x402` 缺失 | MVP 先用 injected；RainbowKit 作下一步对照 `my-nft-dapp` |
